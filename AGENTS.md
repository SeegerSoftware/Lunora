## Cursor Cloud specific instructions

### Overview

Lunora (branded "Elunai") is a Flutter mobile/web app that generates personalized bedtime stories for children using AI (OpenAI). The entire UI is in French. It uses Firebase Auth + Cloud Firestore for backend, Riverpod for state management, and go_router for navigation.

### Flutter SDK

Flutter SDK 3.38.5+ is required (Dart SDK `^3.10.4`). The SDK is installed at `/opt/flutter/bin` and added to `PATH` via `~/.bashrc`.

### Key files (gitignored, must be created locally)

- **`lib/firebase_options.dart`** — Generated by `flutterfire configure`. For local development/CI without Firebase credentials, create a stub file that provides `DefaultFirebaseOptions.currentPlatform` with placeholder values. Without this file, nothing compiles.
- **`dart_defines.json`** — Runtime secrets. Copy from `dart_defines.example.json`. Set `USE_FIREBASE=false` and `USE_REAL_AI=false` for offline development without external services.

### Running the app

```bash
# Web (dev server on port 8080)
flutter run -d web-server --web-port=8080 --dart-define-from-file=dart_defines.json

# Chrome (opens browser)
flutter run -d chrome --dart-define-from-file=dart_defines.json
```

### Lint / Analyze

```bash
flutter analyze
```

No issues expected on a clean checkout with dependencies installed.

### Tests

```bash
flutter test --dart-define=USE_FIREBASE=false
```

**Caveat:** Both `test/widget_test.dart` and `test/app_flow_test.dart` require Firebase to be initialized (they instantiate `LunoraApp` which watches `firebaseAuthSyncProvider`). Without real Firebase credentials or emulator setup, these tests will fail. The `widget_test.dart` is a basic smoke test; `app_flow_test.dart` exercises the full auth/navigation flow in "mock mode" but still needs Firebase Core initialized.

### Architecture notes

- `USE_FIREBASE` defaults to `true` via `dart-define`. When `false`, Firebase init is skipped but all data repositories throw `StateError` since no offline/mock repositories exist.
- `USE_REAL_AI` controls whether OpenAI story generation is enabled. When `false` (or no API key), an `_UnconfiguredStoryGenerationService` is used that throws on any generation attempt.
- The app starts at `/welcome` and redirects based on auth state and child profile presence.
